# Nguồn asset

Toàn bộ file SVG trong thư mục này lấy từ **Noto Emoji**
(https://github.com/googlefonts/noto-emoji), phát hành theo **Apache License 2.0**.

Tải lại bằng: `node apps/server/scripts/fetch-assets.mjs`

Lý do chọn Noto Emoji: nét tròn mềm, mặt dễ thương đúng tông chibi, và hiển thị
đồng nhất trên iOS / Android / Web — khác với emoji hệ thống vốn mỗi nền tảng một kiểu.
